# Updating the Resume

The resume has **one source of truth**: `src/content/resume.md`. From it, the build produces two outputs:

1. The web page at `/resume` (styled like printable paper).
2. `dist/ResumeHimangshuPan.pdf` — generated by Puppeteer printing that web page.

Edit the markdown, both update.

## Workflow

```bash
# 1. Edit
$EDITOR src/content/resume.md

# 2. Preview the web version (with hot reload)
npm run dev
# → open http://localhost:4321/resume

# 3. Verify the PDF
npm run build && npm run pdf
xdg-open dist/ResumeHimangshuPan.pdf   # or your PDF viewer

# 4. Commit and push
git add src/content/resume.md
git commit -m "resume: <what changed>"
git push
```

GitHub Actions regenerates the PDF and republishes the site automatically.

## Print styling

The PDF uses `src/styles/resume-print.css`. It:

- Sets A4 page size with 16/18mm margins
- Forces white background and dark text (overrides the site's dark theme)
- Uses Inter for body + JetBrains Mono for headings
- Hides the nav, footer, and "Download PDF" button (`.print-hide` and `hideChrome={true}`)

If a section is breaking across pages awkwardly, you can add a manual page break in `resume.md`:

```html
<div style="break-before: page;"></div>
```

## Filename

The PDF is **always** named `ResumeHimangshuPan.pdf`. That's hardcoded in `scripts/build-resume-pdf.mjs`. To rename: change the `outPath` line in that file *and* update the two `<a href="/ResumeHimangshuPan.pdf">` links (search for the string).
